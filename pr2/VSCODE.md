# Запуск в VS Code

Открой корень репозитория и выполни `.\run.bat` во встроенном терминале.
Останови Flask через Ctrl+C перед переключением этапа.

- Этап 1: `git switch --detach main~2`.
- Этап 2: `git switch --detach main~1`.
- Этап 3: `git switch main`.

На этапах 2 и 3 открой http://127.0.0.1:5000/ после запуска.
